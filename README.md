# Student Expense Tracker

A beginner-friendly Python application for tracking and managing student expenses.

## Features

- Add daily expenses
- View saved expenses
- Store expense data in a text file
- Simple and easy-to-use Python program

## Technologies Used

- Python
- File Handling

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Run:

```bash
python expense_tracker.py
